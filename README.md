# Stepik Fast Complete

**Юзерскрипт для stepik.org.** Сам сохраняет зачтённые ответы, вставляет их одним нажатием
и решает задания, которых ещё нет в общей папке.

[![version](https://img.shields.io/badge/version-6.21.0-blue?style=flat-square)](stepik-gist-sync.user.js)
[![Tampermonkey](https://img.shields.io/badge/Tampermonkey-нужен-orange?style=flat-square)](https://www.tampermonkey.net/)
[![stepik.org](https://img.shields.io/badge/stepik.org-работает-2ea44f?style=flat-square)](https://stepik.org)

</div>

---

## Что он делает

- **Сохраняет ответы сам.** Решил задание правильно — ответ уехал в общую папку. Ничего нажимать не надо. Непринятые ответы в папку не попадают: там лежат только проверенные. Идёт сохранение — справа снизу крутится индикатор; он пропал, значит ответ сохранён.
- **Вставляет одним нажатием.** В следующий раз рядом с заданием появляется скобка **«есть решение»**.
- **Решает то, чего нет в папке.** Нажал «ИИ» — решение появляется тут же, печатается в редакторе и проверяется запуском кода.
- **Проходит задания пачкой.** Можно пройти выбранные уроки подряд и собрать их в документ Word со скриншотами.

## Установка

1. Поставь расширение **[Tampermonkey](https://www.tampermonkey.net/)** — оно есть для Chrome, Edge, Firefox и Opera.

2. Открой ссылку и нажми **«Установить»**:

   **[→ Установить скрипт](https://raw.githubusercontent.com/NOTyeamu/Stepik-Fast-Complete/main/stepik-gist-sync.user.js)**

3. Зайди на любой урок на stepik.org. **Настраивать ничего не нужно.**

При первом запуске скрипт предложит короткое **знакомство**: покажет, где панель заданий,
где скоба с готовым ответом и где чат с ИИ. Можно пропустить — тогда он больше не спросит.

<details>
<summary><b>Как обновить скрипт</b></summary>

Tampermonkey сам проверяет обновления примерно раз в сутки. Чтобы обновиться сразу:
значок Tampermonkey → **«Проверить обновления скриптов»**.

Если версия всё ещё старая — подожди пару минут, файл по ссылке обновляется с небольшой
задержкой.
</details>

## Как пользоваться

### Скобка «есть решение»

Решил задание правильно — ответ сохранился. В следующий раз рядом с редактором появляется
скобка:

> **есть решение** · `вставить` · `/` · `нет`

- **вставить** — подставляет ответ в редактор или отмечает варианты в тесте;
- **нет** — убирает скобку до следующего раза.

Скобка обнимает именно редактор, а не всю карточку задания. Если справа не хватает места,
страница ужимается влево, чтобы она поместилась.

### Решение от ИИ

Нужен ответ, которого нет в папке? Нажми **«ИИ»** в скобке или **«Спросить ИИ»** внизу блока —
и под редактором появится чат с решением.

Что происходит дальше:

1. ИИ думает — в чате видно «ИИ пишет решение…» со счётчиком секунд;
2. **печатает решение прямо в редакторе** — построчно, как будто пишет человек;
3. **сам запускает код** и показывает вывод тут же, в чате;
4. не прошло — читает отчёт, **исправляет и вставляет заново**.

Кнопку **«Отправить на проверку»** скрипт не нажимает никогда: отправка — твоё решение.

Проваленные тесты в отчёте выделены **красным**, пройденные — зелёным.

<details>
<summary><b>Тесты с галочками</b></summary>

Варианты ответа показываются прямо в чате: слева **зелёный кружок**, если верный ответ один,
или **зелёный квадратик**, если верных может быть несколько. Выбранное заливается — сразу
видно, что отмечено на странице.

Если проверка не приняла ответ, скрипт запоминает, что этот вариант не подошёл, и выбирает
**другой** — а не возвращает тот же самый. Выбирает он только те варианты, что подходят:
если модель перечислит весь список подряд, скрипт переспросит и всё равно отметит не всё.
</details>

<details>
<summary><b>Задания на сопоставление</b></summary>

«Сопоставьте часть метода с её назначением» — скрипт читает оба столбца, просит ИИ порядок
и **расставляет значения сам**: в чате видно пары «подпись → значение», а на странице правый
столбец встаёт на нужные места. Остаётся нажать «Отправить на проверку».

Ответ здесь короткий, поэтому скрипт **не тратит время на медленные модели**: берёт быструю
и останавливает ожидание через 25 секунд, если сервис не ответил.
</details>

<details>
<summary><b>Задания с таблицей «отметьте верные ячейки»</b></summary>

Таблица, где в каждой строке написан код, а отметить нужно один из столбцов («true»,
«false», «Ошибка»). Скрипт читает строки и столбцы, спрашивает у ИИ столбец для каждой
строки и **отмечает ячейки сам**. В чате видно, что выбрано:

```
int.TryParse("42", out int n)      →  true
int.TryParse("сорок", out int n)   →  false
int.Parse("abc")                   →  Ошибка (FormatException)
```
</details>

<details>
<summary><b>Задания, где ответ пишут в поле</b></summary>

Скрипт пишет ответ прямо в поле и говорит «Осталось нажать «Отправить на проверку»».
Ничего запускать там не надо — редактора кода в таких заданиях нет.
</details>

<details>
<summary><b>Кнопки в шапке блока</b></summary>

| Кнопка | Что делает |
| --- | --- |
| модель | выбрать модель ИИ |
| 🗑 | **очистить чат** — начать разговор заново, блок остаётся на месте |
| ✕ | **закрыть окно** — вернуть блок можно кнопкой «ИИ» у задания |
</details>

<details>
<summary><b>Пройти задания пачкой и собрать в Word</b></summary>

Кнопка в шапке урока (рядом с полноэкранным режимом) открывает панель вместо списка уроков.
Кнопки идут одна под другой во всю ширину.

- **Пройти и отправить** — сначала спросит диапазон уроков, потом пройдёт их, вставит
  сохранённые ответы и нажмёт «Отправить на проверку» за тебя.
- **Собрать в Word** — делает скриншоты заданий с кодом и собирает документ `.docx`.
- **Спросить ИИ по шагу** — решить текущее задание.
- **Остановить** — прерывает обход.
- **Настройки** — токен записи, ключ ИИ и адрес прокси. Всё хранится на твоём компьютере.

Вкладку во время обхода лучше не закрывать: между заданиями страница перезагружается,
но прогресс сохраняется.
</details>

<details>
<summary><b>Горячие клавиши</b></summary>

| Клавиши | Действие |
| --- | --- |
| `Ctrl+Alt+I` | вставить сохранённое решение |
| `Ctrl+Alt+S` | сохранить ответ принудительно |
| `Ctrl+Alt+D` | отчёт самопроверки |
</details>

## Меню Tampermonkey

| Пункт | Что делает |
| --- | --- |
| ✨ **ИИ: решить текущий шаг** | попросить решение для текущего задания |
| 📋 **Показать решение от ИИ** | вернуть на экран последнее решение |
| ⚙ **Токен записи** | нужен, чтобы сохранять ответы |
| 🔄 **Обновить список ответов** | подтянуть свежий список |
| 🧪 **Проверка хранилища** | покажет, всё ли на месте |

## Где хранятся ответы

В этом же репозитории, в папке [`answers/`](answers/) — по файлу на задание:

```
answers/l1793281_s8.cs     решение на C#
answers/l1793281_s9.json   тест с вариантами
```

Ответы **только добавляются**: существующий файл никогда не перезаписывается.
Испортить или удалить папку нельзя — её ведёт робот, который откатывает посторонние правки.

## Частые вопросы

<details>
<summary><b>Ответ не сохраняется</b></summary>

Нужен токен записи: значок Tampermonkey → **⚙ Токен записи**.
Без него скрипт умеет только вставлять готовые ответы.
</details>

<details>
<summary><b>Скобка «есть решение» не появилась</b></summary>

Обнови страницу. Если и после этого нет — значит ответа для этого шага в общей папке пока
нет. Нажми в скобке **«ИИ»**.
</details>

<details>
<summary><b>ИИ не отвечает</b></summary>

Подожди немного и нажми ещё раз. Если ничего не меняется — напиши
[в issues](https://github.com/NOTyeamu/Stepik-Fast-Complete/issues).
</details>

<details>
<summary><b>ИИ ответил «неполный ответ»</b></summary>

Модель упёрлась в свой лимит. Нажми «Спросить заново» или выбери модель посильнее —
например **Kimi K2.7 Code** или **DeepSeek V4 Pro**.
</details>

<details>
<summary><b>Решение не вставилось в редактор</b></summary>

Обычно помогает нажать **«Изменить решение»** на странице (её показывает Stepik после
неудачной отправки) и попросить ИИ снова. Скрипт делает это сам, но если страница была
в необычном состоянии — попробуй вручную.
</details>
